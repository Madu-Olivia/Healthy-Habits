# 🧠 Healthy Study Habits

A simple and responsive webpage that promotes **healthy study habits for students**.  
This project combines **health and academics**, showing how students can maintain productivity while also taking care of their physical and mental well-being.

The website presents helpful tips such as balancing study time and breaks, choosing brain-boosting snacks, maintaining good posture, and getting enough sleep.

---

## 📖 Project Description

The **Healthy Study Habits** webpage was designed to provide students with practical advice on studying effectively while staying healthy.

The layout follows a clean and structured card-style design where information is divided into sections, making it easy to read and navigate.

---

## ✨ Features

- Clean and simple user interface
- Structured informational sections
- Soft and attractive color scheme
- Responsive layout that adapts to different screen sizes
- Organized content boxes for readability

---

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **Media Queries** for responsive design

---

## 📱 Responsive Design

The website is fully responsive and adapts to different devices including:

- Desktop computers
- Tablets
- Mobile phones

Media queries were used to adjust:

- Font sizes
- Container width
- Image responsiveness
- Padding and spacing

This ensures the website remains readable and visually balanced on all screen sizes.
